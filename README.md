#  Project DUM-E: Robotic Arm Systems

Welcome to the development repository for **DUM-E**, a custom robotic arm system inspired by the classic mechanical assistant from Iron Man. This project is built to explore physical hardware automation, computer vision, and coordinate physics.

---

##  Project Objectives
* **Kinematics & Control:** Writing smooth servo motor mapping routines.
* **Computer Vision:** Tracking objects using camera inputs.
* **Simulated Prototyping:** Testing digital circuit flows before physical deployment.
* **Utilizing AI:** ( Gemini, ChatGPT and Grok's API) as the 'brain' of the project - from identifying objects, person(s) and more to working as an Alexa and Home Automation System.

##  Tech Stack & Components
* **Hardware:** Microcontroller platform (ESP32 / Raspberry Pi 3), Servo Motors.
* **Languages:** Python / C++.
* **Development Environment:** VS Code & GitHub Ecosystem.
