# 📐 DUM-E 3D Print Library

This directory contains the complete structural `.stl` blueprint models for the DUM-E robotic hand and articulating forearm chassis. 

### 📂 Blueprint Guide:
* **Base Platform:** `Tabla_Alt.stl`, `Alt_Govde.stl`, `Alt_Kasa.stl`
* **Arm Structure:** `Alt_Kol.stl`, `On_Kol.stl`, `Bilek.stl`
* **Articulated Hand:** `El.stl`, `El_Ust.stl`, `Parmak.stl`, `Disli.stl`
